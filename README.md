# e-plantShopping 🌱

## Project Overview

**e-plantShopping** is an online plant shopping application developed as part of a final project. The application, called **Paradise Nursery**, provides a user-friendly interface for browsing and purchasing a variety of houseplants.

Users can explore different plant categories, view plant details, add plants to their shopping cart, and manage their cart quantities. The application dynamically updates item quantities and calculates the total cost as users add, remove, or adjust plants in their cart.

## Features

- **Landing Page:** Welcomes users to Paradise Nursery and provides navigation to the plant catalog.
- **Navigation Bar:** Provides links to the home page, product listing page, and shopping cart.
- **Plant Catalog:** Displays a variety of houseplants organized into categories.
- **Plant Details:** Shows each plant's image, name, description, and price.
- **Add to Cart:** Allows users to add plants to their shopping cart.
- **Dynamic Cart Quantity:** Updates the cart item count as plants are added or removed.
- **Quantity Management:** Allows users to increase or decrease the quantity of each plant.
- **Delete Items:** Removes individual plant types from the shopping cart.
- **Price Calculation:** Automatically calculates subtotals and the total cost of items in the cart.
- **Continue Shopping:** Allows users to return to the plant catalog.
- **Checkout:** Provides a checkout button for the shopping experience.

## Getting Started

Follow these steps to run the project locally.

### Prerequisites

Make sure you have the following installed:

- [Node.js](https://nodejs.org/)
- npm (included with Node.js)
- Git

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/KrishnaMahale/e-plantShopping.git
   ```

2. Navigate to the project directory:

   ```bash
   cd e-plantShopping
   ```

3. Install the project dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL displayed in your terminal to view the application in your browser.

**Note:** The commands above assume the project uses a Vite-based React setup. If your project uses Create React App or another setup, follow the scripts defined in `package.json`.

## How to Use

1. Open the Paradise Nursery application.
2. Navigate to the plant listing page.
3. Browse the available plants and their details.
4. Click **Add to Cart** to add a plant to your shopping cart.
5. Open the cart to view selected plants.
6. Use the plus and minus buttons to adjust quantities.
7. Click **Delete** to remove a plant from the cart.
8. Review the automatically updated subtotal and total cost.
9. Select **Continue Shopping** to browse more plants or **Checkout** to proceed to the checkout step.
